# 🌱 Smart Soil Monitoring

### Crop Health and Soil Salinity Screening System

## Overview

Smart Soil Monitoring is a web-based agricultural monitoring
prototype that helps users examine visible crop conditions
and assess potential soil salinity concerns.

Users can upload plant images, select a crop and growth stage,
enter soil electrical conductivity (EC), and receive a preliminary
crop-condition assessment with management recommendations.

## Problem

Soil salinity and unsuitable environmental conditions can
affect crop development. Accessible monitoring tools can help
users investigate crop conditions and identify when further
soil testing may be needed.

## Features

- Plant image upload and image-based analysis
- Crop and growth-stage selection
- Manual soil electrical-conductivity (EC) input
- Estimated visible plant-stress score
- Crop health and growth assessment
- Environmental sensor demonstration values
- Scan history and comparison
- Downloadable PDF assessment report
- Arduino serial-communication interface under development

## Technology Stack

- Python
- Streamlit
- OpenCV
- Pandas
- ReportLab
- PySerial
- Arduino Uno integration planned
